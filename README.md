This project explores quality engineering for a conversational AI voice agent built for a fictional Vietnamese-inspired café.

**QA coverage includes:**
- Menu and pricing validation
- Order calculation accuracy
- Multi-turn conversation and order updates
- Hallucination prevention
- Allergy safety and payment privacy

The repository documents manual test cases, test execution results, prompt iterations, and defects discovered during testing.

**Tech Stack:** Deepgram Voice Agent, Google Gemini, Deepgram Flux, Aura TTS, OBS Studio.
